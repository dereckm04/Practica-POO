# Práctica POO

Este repositorio contiene una práctica de **Programación Orientada a Objetos (POO) en PHP**.

La práctica reúne varios ejercicios para trabajar conceptos de POO y entender cómo se utilizan las clases y diferentes características de PHP.

## ¿Qué hay en el repositorio?

Entre los ejercicios se encuentran:

* **Coche:** ejercicio relacionado con la creación y uso de clases.
* **Late Static Binding:** ejemplo para trabajar con este concepto de PHP.
* **Clase Final:** ejercicio utilizando clases `final`.
* **Círculo:** ejemplo utilizando una clase para realizar operaciones relacionadas con un círculo.
* **Problema 5:** ejercicio adicional de la práctica.

## Archivos principales

* `problema1_Coche.php`
* `problema2_LateStaticBinding.php`
* `problema3_ClaseFinal.php`
* `problema4_Circulo.php`
* `problema5/`

## ¿Qué se utilizó?

* PHP
* Programación Orientada a Objetos
* Visual Studio Code
* WAMP

## ¿Cómo ejecutarlo?

Para probar los ejercicios se puede utilizar **WAMP** como servidor local.

Se coloca la carpeta del proyecto dentro de:

```text
C:\wamp64\www\
```

Luego se inicia WAMP y se accede al proyecto desde el navegador:

```text
http://localhost/Practica-Poo/
```

También se pueden abrir los diferentes archivos `.php` para probar cada ejercicio por separado.

## Objetivo

El objetivo de esta práctica es familiarizarse con la **Programación Orientada a Objetos en PHP**, utilizando clases y algunas de las características que ofrece el lenguaje.
